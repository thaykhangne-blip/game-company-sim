# Gacha Studio Simulator

A browser-based management sim about building a game company inspired by the modern anime-style gacha and live-service game industry.

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Current prototype: Foundation
- Company setup: company name, founding year, founder / CEO.
- Basic validation and local browser save.
- Starter company dashboard with seed-stage resources and studio profile.
- Reset / create a new company flow.
- Responsive dark studio UI.

## Planned systems
1. Company setup and time progression
2. Departments, hiring, staff skills, and morale
3. Game IP creation, development phases, budgets, and release planning
4. Gacha design: characters, rarity, banners, pity, monetization, and player sentiment
5. Live operations: patches, events, content cadence, and crisis response
6. Financial statements, revenue, operating costs, and market competition
7. Community, ratings, platform relations, and global expansion

## Tech
Vanilla HTML, CSS, and JavaScript. State is currently stored in localStorage; simulation persistence and balancing will be expanded in later iterations.
